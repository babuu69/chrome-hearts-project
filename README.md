# Chrome Hearts — Beyond the Ordinary

An independent editorial website exploring Chrome Hearts' visual identity, craftsmanship, design language, and cultural influence. Created as a school project.

## Project structure

```
chrome-hearts-project/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
│   └── README.md
└── README.md
```

## Run locally

Open `index.html` in a browser, or use a local development server (for example, VS Code Live Server).

## Deployment

This is a static website. For Netlify, connect this GitHub repository and use:
- Build command: leave empty
- Publish directory: `.`

## Notes

The page currently loads its editorial photography from external image URLs and its fonts from Google Fonts. Those sources need an internet connection. The contact form is a front-end demo: it prepares/copies the message but does not send email.
